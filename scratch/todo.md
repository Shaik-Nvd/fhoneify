# Cashify Pricing Analyzer - Feature Tracker

## Core Features

### Phase 1: Backend Infrastructure
- [ ] Cashify URL parser to extract product ID and variant info
- [ ] Automated browser questionnaire traversal engine
- [ ] Baseline price extraction (Flawless condition)
- [ ] Single-variable edge case testing logic
- [ ] Price deduction calculation (absolute and percentage)
- [ ] Algorithm classification (Additive/Multiplicative/Hybrid)
- [ ] Analysis results storage in database

### Phase 2: Frontend UI
- [ ] URL input field with validation
- [ ] Analysis loading state with progress indicator
- [ ] Base Price Table display
- [ ] Deduction Matrix display (with ₹ and % columns)
- [ ] Algorithm Hypothesis display
- [ ] Results dashboard layout
- [ ] Analysis history list view
- [ ] Comparison view for multiple analyses

### Phase 3: Data Persistence

- [ ] Comparison logic between analyses
